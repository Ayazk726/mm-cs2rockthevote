//
// A trailing tier field is optional and is shown when DisplayKzTiers is enabled.
// It uses the CS2KZ website's map list format: the classic (CKZ) tier, then the
// vanilla (VNL) tier in parentheses.
//
// mapname:workshopid:ckz         - classic tier only, e.g. "kz_igneous:3102712799:3"
// mapname:workshopid:ckz(vnl)    - both tiers, e.g. "kz_igneous:3102712799:3(3)"
//
// Tiers are 1-10. A missing or invalid value means this file has no tier: the
// CS2KZ API is still queried and its tier, if any, is shown instead. Tiers are
// not shown only when neither source has one. API tiers take precedence.
// A line with just a workshop id keeps its old meaning: "kz_grotto:2" is
// workshop id 2, not tier 2.
